```
요청
 │

 │
 ▼
┌──────────────────────────────────────────┐
│ When 버그/장애 → 사용자와 진단 먼저       │  Phase 0.5

└──────────────────────────────────────────┘
 │
 ▼
┌──────────────────────────────────────────┐
│ 영향 분석 → 사용자 승인                    │  Phase 1
└──────────────────────────────────────────┘
 │
 ▼
┌──────────────────────────────────────────┐
│ When 3+ 파일/의존성 → 분할                │  Phase 1.5

│ Scout 의존성 분석 (분할 + DI 수집)         │
└──────────────────────────────────────────┘
 │
 ▼
┌──────────────────────────────────────────────────────────────┐
│ ▶ 체인 실행 (P→S→W)                                         │
│                                                              │
│   When 파일 모름          When 파일 앎                       │
│   ┌────────────────┐    ┌────────────────┐                  │
│   │ Scout          │    │ Planner        │                   │
│   │  (파일 탐색)   │    │  (6섹션 brief) │                    │
│   │     ↓          │    │     ↓          │                    │
│   │ Planner        │    │ Scout          │                   │
│   │  (6섹션 brief) │    │  (코드 정찰)   │                   │
│   │     ↓          │    │     ↓          │                   │
│   │ Scout          │    │ Worker         │                   │
│   │  (코드 정찰)   │    │  (plan.md 실행) │                   │
│   │     ↓          │    └────────────────┘                  │
│   │ Worker         │                                        │
│   │  (plan.md 실행) │                                       │
│   └────────────────┘                                        │
│                                                              │
│   모든 호출: context: "fresh"                                │
│   Worker brief: plan.md에서만 (Planner가 작성)                │
│   DI: brief에 타입 시그니처 포함 ("see xxx.ts" 금지)         │
│   SCOPE: Target Files + DI만 읽기                             │
└──────────────────────────────────────────────────────────────┘
 │
 ▼
┌──────────────────────────────────────────┐
│ When 체인 실패 → failover                  │  Failover
│                                            │
│ Planner 오계획    → 재실행 + giving of pain │
│ Planner 과다 읽기 → 재실행 + Read ONLY     │
│ Scout 연결 오류   → 재시도 → Giver가 대체  │
│ Worker 연결 오류  → 재시도 → Worker-only   │
│ Worker 과다 읽기  → 재실행 + 강화 DI       │
│ Worker 범위 이탈  → 재실행 + 좁힌 Scope    │
│ 3회 동일 실패     → 사용자에게 보고        │
└──────────────────────────────────────────┘
 │
 ▼
┌──────────────────────────────────────────┐
│ When 다음 체인 있음 → 연속 실행            │  Phase 4
│ 아니면 → 결과 보고                         │
│                                            │
│ DI 검증: 이전 체인 실제 구현과 비교         │
│ 브랜치 상태 보고 (merge 안 함)              │
└──────────────────────────────────────────┘
```
